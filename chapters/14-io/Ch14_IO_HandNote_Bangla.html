Section 01

File ও Directory Reference করা

File system-এর ধারণা

Storage device-এর ভেতরে একটি file data ধরে রাখে। File গুলো directory ব্যবহার করে হায়ারার্কিতে সাজানো হয় — directory এমন একটি অবস্থান যা file এবং অন্য directory দুটোই রাখতে পারে। Java-তে আমরা প্রায়ই directory-কে file-এর মতোই ট্রিট করি, একই class ও method ব্যবহার করে; এই অধ্যায়ে "file" বলতে প্রায়ই "file বা directory" বোঝানো হয়।

File system কম্পিউটারের ভেতরে data read/write-এর দায়িত্বে থাকে; JVM স্বয়ংক্রিয়ভাবে local file system-এর সাথে সংযোগ করে। Root directory হলো সবচেয়ে উপরের directory — Windows-এ C:\, Linux-এ /। Path হলো file বা directory-র একটি উপস্থাপনা; separator-এর বাঁ দিকের মান ডান দিকের মানের parent।

Absolute বনাম relative — exam-এর কনভেনশন

  • Path যদি forward slash (/) দিয়ে শুরু হয়, এটি absolute, root হলো / — যেমন /bird/parrot.png।
  • Path যদি drive letter (C:) দিয়ে শুরু হয়, এটি absolute, root হলো ওই drive letter — যেমন C:/bird/info।
  • অন্যথায় এটি relative path — যেমন bird/parrot.png।
Symbolবর্ণনা
.বর্তমান directory-র রেফারেন্স
..বর্তমান directory-র parent-এর রেফারেন্স

Current directory /fish/shark/hammerhead হলে ../swim.txt সমতুল্য /fish/shark/swim.txt, আর ../../clownfish সমতুল্য /fish/clownfish। /fish/clownfish/../shark/./swim.txt-এর মতো অপ্রয়োজনীয় অংশ normalize() দিয়ে সরানো যায়।

Symbolic link হলো একটি বিশেষ file যা অন্য file বা directory-র pointer হিসেবে কাজ করে। /zoo/user/favorite থেকে /fish/shark-এ link থাকলে /fish/shark/swim.txt ও /zoo/user/favorite/swim.txt একই file নির্দেশ করে।

✓ KEY RULE

পুরোনো I/O API symbolic link সমর্থন করে না। NIO.2-তে symbolic link তৈরি, শনাক্ত ও navigate করার পূর্ণ সাপোর্ট আছে।

File তৈরি করা

File zooFile1 = new File("/home/tiger/data/stripes.txt");
File zooFile2 = new File("/home/tiger", "data/stripes.txt");

File parent = new File("/home/tiger");
File zooFile3 = new File(parent, "data/stripes.txt");

System.out.println(zooFile1.exists());

তিনটিই একই অবস্থান নির্দেশ করে। শেষ constructor-এ parent হিসেবে null pass করলে সেটি উপেক্ষা করা হয় এবং এটি একক-String constructor-এর মতোই আচরণ করে।

⚠ EXAM TRAP

তিন-parameter-এর কোনো File constructor নেই — new File("/weather", "winter", "snow.dat") compile হয় না। (File, String) constructor আছে, কিন্তু (String, File) constructor নেই।

Path তৈরি করা

Path একটি interface, তাই এর কোনো constructor নেই। সাধারণ factory method:

public static Path of(String first, String... more)
Path zooPath1 = Path.of("/home/tiger/data/stripes.txt");
Path zooPath2 = Path.of("/home", "tiger", "data", "stripes.txt");

System.out.println(Files.exists(zooPath1));

Varargs মানগুলো একত্র হয় এবং OS-নির্ভর file separator দিয়ে স্বয়ংক্রিয়ভাবে আলাদা হয়।

Path পাওয়ার চারটি উপায়

  • Path.of("/home", "tiger", "data") — পছন্দনীয় factory method।
  • Paths.get("/home", "tiger", "data") — পুরোনো Paths helper class; signature একই, তবে ভবিষ্যতে deprecated হতে পারে।
  • FileSystems.getDefault().getPath("/home/tiger/data/stripes.txt") — Path.of() ভেতরে এটাই ব্যবহার করে।
  • Path.of(URI.create("https://www.selikoff.net")) — URI থেকে, file:// বা https://-এর মতো scheme সহ।
⚠ EXAM TRAP

new Path("jaguar.txt") compile হয় না — Path একটি interface। আর Path-এর static method হলো of(), get() নয়; get() আছে Paths-এ। এই দুটি নাম অদলবদল করাই ক্লাসিক distractor।

File ও Path-এর মধ্যে রূপান্তর

File file = new File("rabbit");
Path newPath = file.toPath();
File backToFile = newPath.toFile();

অনেক পুরোনো library File ব্যবহার করে। নতুন application-এ NIO.2-এর Path ব্যবহার করুন — এতে অনেক বেশি feature আছে।

⚠ EXAM TRAP

java.io.File হলো I/O class; Files হলো NIO.2-এর helper class, যার method গুলো static এবং Path instance নিয়ে কাজ করে, File নিয়ে নয়। API-এর মধ্যে নাম মেলানোর ফাঁদেও সাবধান: এটি Files.createDirectory(), Files.mkdir() নয়। Files.mkdir(...) লিখলে compile হয় না।

✓ KEY RULE

যেসব method file access বা পরিবর্তন করে, বিশেষত Files-এর, সেগুলো সাধারণত IOException declare করে — আর সেই checked exception অবশ্যই handle বা declare করতে হবে। Exam-এর একটি ঘন ঘন আসা কৌশল হলো throws IOException ছাড়া Files.deleteIfExists() বা Files.size() কল করা: সেটি compile হয় না। উল্লেখযোগ্য ব্যতিক্রম Files.exists() — file না থাকলে যদি এটি exception ছুড়ত, তাহলে false ফেরত দিতেই পারত না।

Path immutable

Path p = Path.of("whale");
p.resolve("krill");
System.out.println(p);   // whale — the result was discarded
⚠ EXAM TRAP

String-এর মতোই Path immutable। ফলাফল assign না করে Path-এর কোনো method কল করা মানে কার্যত কিছুই না করা। Exam প্রায়ই p1.normalize().relativize(x);-কে আলাদা line-এ লুকিয়ে রেখে পরে অপরিবর্তিত p1 প্রিন্ট করে।

Path দেখা ও অংশ নেওয়া

Path path = Path.of("/land/hippo/harry.happy");
System.out.println("The Path is: " + path);
for(int i=0; i<path.getNameCount(); i++)
   System.out.println("   Element " + i + " is: " + path.getName(i));
The Path is: /land/hippo/harry.happy
   Element 0 is: land
   Element 1 is: hippo
   Element 2 is: harry.happy
  • toString()-ই Path-এর একমাত্র method যা String ফেরত দেয়; বাকিরা সাধারণত Path ফেরত দেয়।
  • getNameCount() ও getName() root অন্তর্ভুক্ত করে না, absolute path হলেও নয়।
  • Path.of("/").getNameCount() হলো 0, আর এতে getName(0) কল করলে IllegalArgumentException ছোড়ে।
var p = Path.of("/mammal/omnivore/raccoon.image");
p.subpath(0, 3);   // mammal/omnivore/raccoon.image

p.subpath(0, 4);   // IllegalArgumentException — max index is 3
p.subpath(1, 1);   // IllegalArgumentException — empty path

subpath() inclusive beginIndex ও exclusive endIndex নেয়, zero-indexed, root বাদ দেয় — এবং absolute path-এ প্রয়োগ করলেও relative path ফেরত দেয়।

resolve() — concatenation

Path path1 = Path.of("/cats/../panther");
Path path2 = Path.of("food");
System.out.println(path1.resolve(path2));    // /cats/../panther/food

Path path3 = Path.of("/turkey/food");
System.out.println(path3.resolve("/tiger/cage"));   // /tiger/cage
✓ KEY RULE

resolve() দেখলেই ভাবুন concatenation। এটি path symbol পরিষ্কার করে না। আর argument যদি absolute path হয়, সেই argument-ই ফেরত আসে — resolve() দিয়ে দুটি absolute path জোড়া দেওয়া যায় না।

relativize() — একটি থেকে আরেকটিতে যাওয়ার পথ

var path1 = Path.of("fish.txt");
var path2 = Path.of("friendly/birds.txt");
System.out.println(path1.relativize(path2));   // ../friendly/birds.txt
System.out.println(path2.relativize(path1));   // ../../fish.txt
⚠ EXAM TRAP

relativize()-এর জন্য দুটি path-ই হয় absolute, নয় relative হতে হবে; মেশালে IllegalArgumentException। Windows-এ দুটি absolute path-এর root/drive letter-ও এক হতে হবে, নইলে exception।

Path.of("/primate/chimpanzee").relativize(Path.of("bananas.txt"));
   // IllegalArgumentException

normalize() ও toRealPath()

Path.of("./armadillo/../shells.txt").normalize();   // shells.txt
Path.of("/cats/../panther/food").normalize();      // /panther/food
Path.of("../../fish.txt").normalize();             // ../../fish.txt (unchanged)

var p1 = Path.of("/pony/../weather.txt");
var p2 = Path.of("/weather.txt");
p1.equals(p2);                                 // false
p1.normalize().equals(p2.normalize());         // true

normalize() কেবল যেসব redundancy কমানো যায় সেগুলোই সরায় — এর মূল উদ্দেশ্য সমতুল্য path তুলনা করতে দেওয়া।

normalize()

  • সম্পূর্ণ textual — কমানো-যোগ্য . ও .. সরায়
  • File system স্পর্শ করে না
  • File না থাকলেও কখনো throw করে না

toRealPath()

  • Redundant symbol সরায় এবং relative হলে working directory-র সাথে জোড়ে

  • Path না থাকলে exception ছোড়ে
  • Path.of(".").toRealPath() দিয়ে current working directory পাওয়া যায়

তৈরি, copy, move, delete

createDirectory()

  • Directory আগে থেকেই থাকলে throw করে
  • Parent directory না থাকলেও throw করে

createDirectories()

  • Target এবং অনুপস্থিত সব parent তৈরি করে
  • সবকিছু আগে থেকেই থাকলে কিছু না করেই শেষ হয় — exception নেই
Files.copy(Path.of("/panda/bamboo.txt"), Path.of("/panda-save/bamboo.txt"));
Files.copy(Path.of("/turtle"), Path.of("/turtleCopy"));   // SHALLOW copy

Files.copy(Path.of("book.txt"), Path.of("movie.txt"),
   StandardCopyOption.REPLACE_EXISTING);
  • Directory copy করলে সেটি shallow — ভেতরের file ও subdirectory copy হয় না। Deep copy-র জন্য recursion লাগে।
  • REPLACE_EXISTING ছাড়া target আগে থেকেই থাকলে copy() throw করে।
  • I/O stream-এর সাথে দুটি overload: copy(InputStream in, Path target, CopyOption... o) এবং copy(Path source, OutputStream out)।
⚠ EXAM TRAP

File-কে directory-র "ভেতরে" copy করা যেভাবে ভাবছেন সেভাবে কাজ করে না:

var file = Path.of("food.txt");
var directory = Path.of("/enclosure");   // both exist
Files.copy(file, directory);              // throws at runtime

Command টি /enclosure নামে একটি নতুন file তৈরির চেষ্টা করে, আর ওই path আগে থেকেই থাকায় throw করে। /enclosure যদি না থাকত, তাহলে food.txt-এর বিষয়বস্তু নিয়ে /enclosure নামের একটি file তৈরি হতো। সঠিক target হলো /enclosure/food.txt। এটি move()-এর ক্ষেত্রেও প্রযোজ্য।

Files.move(Path.of("C:\\zoo"), Path.of("C:\\zoo-new"));
Files.move(Path.of("mouse.txt"), Path.of("gerbil.txt"),
   StandardCopyOption.ATOMIC_MOVE);

Atomic move হলো একটি একক, অবিভাজ্য operation — file system পর্যবেক্ষণকারী কোনো process কখনো অসম্পূর্ণ বা আংশিক লেখা file দেখে না। File system এটি সমর্থন না করলে AtomicMoveNotSupportedException ছোড়া হয়। খেয়াল রাখুন, ATOMIC_MOVE StandardCopyOption-এর সদস্য হলেও copy()-তে pass করলে সম্ভবত exception ছুড়বে।

delete(Path)

  • void ফেরত দেয়
  • Path না থাকলে throw করে (NoSuchFileException)

deleteIfExists(Path)

  • boolean ফেরত দেয় — delete হলে true, নইলে false
  • Path কেবল অনুপস্থিত থাকলে throw করে না

খালি নয় এমন directory-তে দুটোই throw করে — directory delete করতে হলে সেটি খালি হতে হবে। Path যদি symbolic link হয়, link-টিই delete হয়, তার target নয়। দুটোই IOException declare করে।

isSameFile() ও mismatch()

Files.isSameFile(Path.of("/animals/cobra"), Path.of("/animals/snake"));
   // true — snake is a symbolic link to cobra

Files.mismatch(Path.of("/animals/monkey.txt"), Path.of("/animals/wolf.txt"));
   // 1 — "Harold" vs "Howler" first differ at index 1
  • isSameFile() সব path symbol resolve করে এবং symbolic link অনুসরণ করে — equals() কোনোটিই করে না।
  • বিশেষ ক্ষেত্র: দুটি path equals()-এ সমান হলে isSameFile() file আছে কি না না দেখেই true ফেরত দেয়।
  • mismatch() contents তুলনা করে: file এক হলে -1, নইলে প্রথম পার্থক্যের index।
  • mismatch() symmetric — argument অদলবদল করলেও একই ফল।
Section 03

I/O Stream-এর পরিচয়

I/O stream হলো ক্রমানুসারে উপস্থাপিত data element-এর একটি তালিকা — ধারণাগতভাবে প্রায় অন্তহীন জলের ধারা, যা একবারে এক ঢেউ করে পড়া হয়। যেহেতু একবারে সামান্য অংশই ধরা থাকে, তাই ১ TB ফাইলও খুব কম memory-র প্রোগ্রাম দিয়ে প্রসেস করা যায়।

★ REMEMBER

এখানে "I/O stream" মানে java.io-র stream। বই যখন শুধু "stream" বলে, তখন সেটি অধ্যায় ১০-এর Stream API। এই নামের মিলটাই একটি ইচ্ছাকৃত exam trap।

প্রতিটি I/O stream class শ্রেণিবদ্ধ করার তিনটি অক্ষ

  • Byte বনাম character: byte stream binary data read/write করে, নাম শেষ হয় InputStream/OutputStream-এ; character stream text নিয়ে কাজ করে, নাম শেষ হয় Reader/Writer-এ।
  • Input বনাম output: বেশিরভাগ InputStream-এর একটি সঙ্গী OutputStream আছে, আর বেশিরভাগ Reader-এর একটি Writer।
  • Low-level বনাম high-level: low-level stream সরাসরি data source-এর সাথে যুক্ত; high-level stream আরেকটি stream-কে wrap করে তৈরি হয়।
✓ KEY RULE

নামে "Stream" না থাকলেও character stream-ও I/O stream। আর exam-এর জন্য জানার মতো low-level class কেবল সেগুলোই যেগুলো file নিয়ে কাজ করে — বাকি প্রতিটি non-abstract stream class high-level।

Wrapping

try (var br = new BufferedReader(new FileReader("zoo-data.txt"))) {
   System.out.println(br.readLine());
}

try (var ois = new ObjectInputStream(
         new BufferedInputStream(
            new FileInputStream("zoo-data.ser")))) {
   System.out.print(ois.readObject());
}

High-level stream অন্য high-level stream-ও wrap করতে পারে। এখানে low-level FileInputStream file-এর সাথে যুক্ত, BufferedInputStream performance বাড়ায়, আর ObjectInputStream data-কে Java object হিসেবে ব্যাখ্যা করে।

⚠ EXAM TRAP

ভুল wrapping এই অধ্যায়ের সবচেয়ে প্রচলিত compile trap:

new BufferedInputStream(new FileReader("z.txt"));     // DOES NOT COMPILE
new BufferedWriter(new FileOutputStream("z.txt"));    // DOES NOT COMPILE
new ObjectInputStream(new FileOutputStream("z.txt"));  // DOES NOT COMPILE
new BufferedInputStream(new InputStream());          // DOES NOT COMPILE

প্রথম দুটি Reader/Writer-এর সাথে InputStream/OutputStream মেশায়। তৃতীয়টি input stream-এ একটি OutputStream ঢোকায়। চতুর্থটি ব্যর্থ কারণ InputStream abstract।

★ REMEMBER

নিয়মের ব্যতিক্রম: InputStreamReader একটি Reader যা InputStream নেয়, আর OutputStreamWriter একটি Writer যা OutputStream নেয় — নামে দুই অংশই আছে এমন একমাত্র class এগুলোই। PrintWriter OutputStream বা Writer দুটোই নিতে পারে। PrintReader বলে কিছু নেই, আর PrintStream একটি OutputStream যার নামে "Output" নেই।

Section 04

File Read ও Write করা

Low-level উপায়

void copyStream(InputStream in, OutputStream out) throws IOException {
   int b;
   while ((b = in.read()) != -1) {
      out.write(b);
   }
}
✓ KEY RULE

read() byte নয়, int ফেরত দেয় — কারণ stream-এর শেষ বোঝানোর জন্য byte-এ কোনো অতিরিক্ত মান অবশিষ্ট নেই। -1 মানে stream-এর শেষ। সঙ্গতি রক্ষার জন্য output stream-ও int ব্যবহার করে।

10: void copyStream(InputStream in, OutputStream out) throws IOException {
11:    int batchSize = 1024;
12:    var buffer = new byte[batchSize];
13:    int lengthRead;
14:    while ((lengthRead = in.read(buffer, 0, batchSize)) > 0) {
15:       out.write(buffer, 0, lengthRead);
16:       out.flush();
17:    }
18: }
  • Offset ও length প্রযোজ্য হয় array-এর উপর: offset 3, length 5 মানে array-র ৩ নম্বর অবস্থান থেকে শুরু করে সর্বোচ্চ পাঁচটি মান পড়া।
  • lengthRead return মানটি অত্যন্ত জরুরি। এটি উপেক্ষা করে সবসময় পুরো buffer লিখলে আগের iteration-এর অবশিষ্ট byte জুড়ে যাবে।
  • flush() জমা হওয়া data সঙ্গে সঙ্গে disk-এ লেখার অনুরোধ করে। এর খরচ আছে, তাই মাঝে মাঝে ব্যবহার করুন — প্রতিটি write-এর পরে নয়।
⚠ EXAM TRAP

while(reader.read(buffer) != -1) { writer.write(buffer); }-এর মতো code compile হয় কিন্তু ভুল: এটি আসলে কতটি character পড়া হয়েছে তা উপেক্ষা করে, তাই কেবল তখনই ঠিকভাবে copy করে যখন file-এর দৈর্ঘ্য buffer size-এর ঠিক গুণিতক। নইলে শেষ write-টি অবশিষ্ট character-গুলোর নকল বসায়।

High-level উপায়

26: void copyTextFile(File src, File dest) throws IOException {
27:    try (var reader = new BufferedReader(new FileReader(src));
28:       var writer = new BufferedWriter(new FileWriter(dest))) {
29:       String line = null;
30:       while ((line = reader.readLine()) != null) {
31:          writer.write(line);
32:          writer.newLine();
33:       } } }
  • Source না থাকলে FileNotFoundException (যা IOException inherit করে) ছোড়া হয়।
  • Destination থাকলে সেটি overwrite হয়। Append করতে FileWriter-এ optional boolean দ্বিতীয় parameter দিন।
  • readLine() line break ফেলে দেয়, তাই newLine() সেগুলো ফিরিয়ে দেয়।
  • try-with-resources চেইনের প্রতিটি object বন্ধ করে।

Byte data-র জন্য বেছে নিতেন BufferedInputStream, BufferedOutputStream, FileInputStream ও FileOutputStream, readLine()-এর বদলে readAllBytes() কল করে ফলাফল byte[]-এ রাখতেন।

PrintStream ও PrintWriter

try (var reader = new BufferedReader(new FileReader(src));
   var writer = new PrintWriter(new FileWriter(dest))) {
   String line = null;
   while ((line = reader.readLine()) != null)
      writer.println(line);
}

চারটি মূল method: print(), println(), format() ও printf()।

✓ KEY RULE

Print stream class-এর method গুলো কোনো checked exception ছোড়ে না — নইলে প্রতিবার System.out.print() কল করতে গিয়ে exception ধরতে হতো। এগুলো checkError()-এর মাধ্যমে সমস্যা জানায়, অন্যথায় নীরবে ব্যর্থ হয়। System.out ও System.err হলো PrintStream; System.in একটি InputStream।

Line separator OS ভেদে \n বা \r\n; println() এটি সামলায়। সরাসরি পেতে System.lineSeparator() বা System.getProperty("line.separator") ব্যবহার করুন।

Files দিয়ে সহজতর

String string = Files.readString(input);        Files.writeString(output, string);
byte[] bytes = Files.readAllBytes(input);       Files.write(output, bytes);
List<String> lines = Files.readAllLines(input); Files.write(output, lines);

তিনটিই পুরো file একবারে পড়ে, সব contents memory-তে রাখে — বড় file-এ OutOfMemoryError হতে পারে। Lazy বিকল্প:

try (Stream<String> s = Files.lines(path)) {
   s.filter(f -> f.startsWith("WARN:"))
      .map(f -> f.substring(5))
      .forEach(System.out::println);
}
⚠ EXAM TRAP

readAllLines() একটি List ফেরত দেয়; lines() একটি Stream। তাই readAllLines()-এর ফলাফলে Stream API method পাওয়া যায় না:

Files.readAllLines(Path.of("birds.txt"))
   .filter(s -> s.length() > 2)      // DOES NOT COMPILE
   .forEach(System.out::println);

forEach() দুটোতেই চলে (List একটি Iterable), কিন্তু filter(), map(), flatMap() কেবল Stream-এ।

✓ KEY RULE

NIO.2-এর stream-ভিত্তিক method (Files.list(), Files.lines(), Files.walk(), Files.find()) file system-এর সাথে একটি connection খোলে যা অবশ্যই বন্ধ করতে হবে try-with-resources দিয়ে; terminal operation এগুলো বন্ধ করে না। অধ্যায় ১০-এর stream বন্ধ করার দরকার নেই।

try (var reader = Files.newBufferedReader(input);
     var writer = Files.newBufferedWriter(output)) {
   String line = null;
   while ((line = reader.readLine()) != null) {
      writer.write(line);
      writer.newLine();
   } }

Section 05

Data Serialize করা

Serialization হলো memory-তে থাকা object-কে byte stream-এ রূপান্তরের প্রক্রিয়া; deserialization হলো byte stream থেকে আবার object-এ ফেরানো।

Serializable interface

java.io.Serializable একটি marker interface — এতে কোনো method নেই, তাই যেকোনো class এটি implement করতে পারে। এর উদ্দেশ্য হলো serialize করা process-কে জানানো যে আপনি সঠিক পদক্ষেপ নিয়েছেন।

import java.io.Serializable;
public class Gorilla implements Serializable {
   private static final long serialVersionUID = 1L;
   private String name;
   private int age;
   private Boolean friendly;
   private transient String favoriteFood;
}

একটি class কীভাবে serializable বানাবেন

  • Class-টিকে Serializable চিহ্নিত করতে হবে।
  • প্রতিটি instance member হয় serializable, নয় transient চিহ্নিত, নয়তো serialization-এর সময় null হতে হবে।
  • দ্বিতীয় নিয়মটি recursively প্রয়োগ করুন — serializable একটি field-এর নিজের field যদি serializable না হয়, চেইন ভেঙে যায়।
public class Cat implements Serializable { private Tail tail = new Tail(); }
public class Tail implements Serializable { private Fur fur = new Fur(); }
public class Fur {}    // not Serializable → Cat is not serializable

সমাধান: fur-কে transient করুন, অথবা Fur-কে Serializable বানান। ভুলভাবে তৈরি class serialize করার চেষ্টা করলে NotSerializableException ছোড়া হয়।

⚠ EXAM TRAP
  • শুধু Object type-এর একটি field (যেমন private Object stripes = new Object();) পুরো class-কে non-serializable করে দেয় — Object Serializable implement করে না। Code compile হয় কিন্তু runtime-এ throw করে।
  • Record স্বয়ংক্রিয়ভাবে serializable নয়। record R(String name) {} নয়; record R(String name) implements Serializable {} হ্যাঁ।
  • serialVersionUID সুপারিশকৃত, বাধ্যতামূলক নয়।
  • static field-কে transient করার তেমন প্রভাব নেই — serialVersionUID ছাড়া কেবল instance member-ই serialize হয়।

ObjectOutputStream ও ObjectInputStream

// ObjectInputStream
public Object readObject() throws IOException, ClassNotFoundException
// ObjectOutputStream
public void writeObject(Object obj) throws IOException
void saveToFile(List<Gorilla> gorillas, File dataFile) throws IOException {
   try (var out = new ObjectOutputStream(
           new BufferedOutputStream(new FileOutputStream(dataFile)))) {
      for (Gorilla gorilla : gorillas)
         out.writeObject(gorilla);
   }
}

List<Gorilla> readFromFile(File dataFile) throws IOException, ClassNotFoundException {
   var gorillas = new ArrayList<Gorilla>();
   try (var in = new ObjectInputStream(
         new BufferedInputStream(new FileInputStream(dataFile)))) {
      while (true) {
         var object = in.readObject();
         if (object instanceof Gorilla g)
            gorillas.add(g);
      }
   } catch (EOFException e) {
      // File end reached
   }
   return gorillas;
}
  • readObject() কল করার সময় null ও -1-এর কোনো বিশেষ অর্থ নেই — কেউ ওই মানগুলোও serialize করে থাকতে পারে। তাই একটি infinite loop ব্যবহার করা হয়, যা EOFException-এ শেষ হয়।
  • readObject() checked ClassNotFoundException declare করে, কারণ deserialization-এর সময় class না-ও থাকতে পারে।
  • available() দিয়ে শেষ শনাক্ত করা যায় না — এটি কেবল অন্য thread block না করে পড়া যায় এমন block-সংখ্যা জানায়, আর byte বাকি থাকলেও 0 দিতে পারে।

Deserialization-এ object তৈরির প্রক্রিয়া

✓ KEY RULE

Deserialization-এ serialized class-এর constructor এবং instance initializer কল হয় না। Java hierarchy-তে পাওয়া প্রথম non-serializable parent class-এর no-arg constructor কল করে। Static ও transient field উপেক্ষিত হয়, আর অনুপস্থিত মান Java-র default পায় (null, 0)।

// Mammal.java — NOT Serializable
public class Mammal {
   private int id;
   public Mammal() { this.id = 4; }
}

// Chimpanzee.java
public class Chimpanzee extends Mammal implements Serializable {
   private static final long serialVersionUID = 2L;
   private transient String name;
   private transient int age = 10;
   private static char type = 'C';
   { this.age = 14; }
   public Chimpanzee() { this("Unknown", 12, 'Q'); }
   public Chimpanzee(String name, int age, char type) {
      this.name = name; this.age = age; this.type = type; setId(9);
   }
}
Original:  [name=Ham,  age=2, type=B, id=9], [name=Enos, age=3, type=B, id=9]
From Disk: [name=null, age=0, type=B, id=4], [name=null, age=0, type=B, id=4]
  • name ও age transient → লেখা হয় না; ফিরে আসে null ও 0 হিসেবে।
  • type static → লেখা হয় না; JVM-এ সবশেষে যে মান বসানো হয়েছিল সেটিই দেখায়।
  • Chimpanzee-এর কোনো constructor চলে না, আর age = 14 বসানো instance initializer-ও চলে না।
  • Mammal Serializable নয়, তাই তার no-arg constructor চলে এবং id হয় 4।
  • Serializable class-এর subclass নিজেও serializable, interface উত্তরাধিকারসূত্রে পায়।
★ REMEMBER

private readObject(ObjectInputStream) ও writeObject(ObjectOutputStream) method declare করে serialization কাস্টমাইজ করা যায়। এগুলো override নয় — স্বয়ংক্রিয়ভাবে কল হয়। readObject() শুরু করুন in.defaultReadObject() দিয়ে, আর writeObject() শেষ করুন out.defaultWriteObject() দিয়ে।

System stream

System.out ও System.err দুটোই PrintStream instance; System.in একটি InputStream। System.err আলাদা stream-এ error জানায় — IDE হয়তো ভিন্ন রঙে দেখায়, আর server ভিন্ন log file-এ পাঠাতে পারে।

var reader = new BufferedReader(new InputStreamReader(System.in));
String userInput = reader.readLine();
System.out.println("You entered: " + userInput);
⚠ EXAM TRAP

এই অধ্যায়ে System stream-ই একমাত্র stream যেগুলো try-with-resources-এ ব্যবহার করা হয় না। এগুলো static ও পুরো application-এ শেয়ারড; বন্ধ করলে সব thread-এর জন্য স্থায়ীভাবে অনুপলব্ধ হয়ে যায়। দেখুন কী হয়:

try (var out = System.out) {}
System.out.println("Hello");      // prints NOTHING — fails silently

try (var err = System.err) {}
System.err.println("Hello");      // prints NOTHING — fails silently

var reader = new BufferedReader(new InputStreamReader(System.in));
try (reader) {}
String data = reader.readLine();     // IOException at runtime

PrintStream-এর ক্ষেত্রে নীরবে ব্যর্থ হয়, কারণ এর method কোনো checked exception ছোড়ে না। বেশিরভাগ InputStream implementation বন্ধ stream-এ কাজ করতে গেলে throw করে।

Console class

java.io.Console একটি singleton, কেবল factory method দিয়েই পাওয়া যায়:

Console c = new Console();          // DOES NOT COMPILE — constructors are private

Console console = System.console();
if (console != null) {
   String userInput = console.readLine();
   console.writer().println("You entered: " + userInput);
   console.flush();
} else {
   System.err.println("Console not available");
}
✓ KEY RULE

Console উপলব্ধ না থাকলে System.console() null ফেরত দেয়, যা নির্ভর করে code কোথায় চলছে তার উপর। ব্যবহারের আগে সবসময় null চেক করুন — var c = System.console();-এর ঠিক পরেই c.readLine() কল করা code NullPointerException ছুড়তে পারে।

File attribute জানা

isDirectory() ও isRegularFile()-এর পাশাপাশি Files-এ আছে isSymbolicLink(), যা File পারে না। খেয়াল রাখুন, symbolic link-এর জন্যও isDirectory() বা isRegularFile() true দিতে পারে, যদি link ওই ধরনেই resolve হয়।

Files আরও দেয় isHidden(), isReadable(), isWritable() ও isExecutable()। isHidden() ছাড়া বাকিগুলো কোনো checked exception declare করে না এবং file না থাকলে false ফেরত দেয়।

Directory tree traverse করা

Depth-first search

  • Root থেকে কোনো leaf পর্যন্ত যায়, তারপর ফিরে এসে বাদ পড়া path পূরণ করে
  • অন্তহীন খোঁজ ঠেকাতে search depth সীমা ব্যবহার করে
  • NIO.2-এর Stream API method গুলো এটাই ব্যবহার করে

Breadth-first search

  • পরের depth-এ যাওয়ার আগে প্রতিটি depth-এর সব element প্রসেস করে
  • ভারসাম্যপূর্ণ ও অনুমানযোগ্য
  • বেশি memory লাগে — visited node-এর তালিকা রাখতে হয়
public static Stream<Path> walk(Path start, FileVisitOption... options)
public static Stream<Path> walk(Path start, int maxDepth, FileVisitOption... options)
public long getPathSize(Path source) throws IOException {
   try (var s = Files.walk(source)) {
      return s.parallel()
            .filter(p -> !Files.isDirectory(p))
            .mapToLong(this::getSize)
            .sum();
   }
}
  • walk() lazy evaluation ব্যবহার করে, তাই বিশাল tree-তেও memory কম লাগে।
  • এক-argument সংস্করণের default max depth হলো Integer.MAX_VALUE। Depth 0 মানে কেবল current path নিজেই।
  • Helper getSize() Files.size()-এর IOException-কে UncheckedIOException-এ মুড়ে দেয়, যাতে lambda-র ভেতরে ব্যবহার করা যায়।
✓ KEY RULE

walk() ব্যতিক্রম: বেশিরভাগ NIO.2 method default-এ symbolic link অনুসরণ করে এবং NOFOLLOW_LINKS দিয়ে বন্ধ করা হয়, কিন্তু walk() FileVisitOption.FOLLOW_LINKS না দিলে link অনুসরণ করে না। ওই option ব্যবহার করলে walk() visited path ট্র্যাক করে এবং কোনো path দুবার এলে FileSystemLoopException ছোড়ে (একটি cycle)।

find() দিয়ে directory খোঁজা

public static Stream<Path> find(Path start,
   int maxDepth,
   BiPredicate<Path, BasicFileAttributes> matcher,
   FileVisitOption... options) throws IOException
var path = Path.of("/bigcats");
long minSize = 1_000;
try (var s = Files.find(path, 10,
      (p, a) -> a.isRegularFile()
         && p.toString().endsWith(".java")
         && a.size() > minSize)) {
   s.forEach(System.out::println);
}
  • find() walk()-এর মতোই, তবে একটি BiPredicate নেয় এবং depth limit বাধ্যতামূলক।
  • BiPredicate-এর দুটি parameter হলো একটি Path ও একটি BasicFileAttributes — Java নিজেই attribute এনে দেয়।
  • maxDepth 0 মানে কেবল শুরুর path-টুকুই খোঁজা হয়, তাই কোনো directory-র নিচের symbolic link খুঁজলে কিছুই প্রিন্ট হবে না।
⚠ EXAM TRAP

Files.walk() একটি Stream<Path> ফেরত দেয়, তাই এর উপর filter() এক-parameter-এর Predicate নেয়। walk()-এর পরে .filter((p, a) -> ...) লিখলে compile হয় না — দুই-parameter-এর BiPredicate রূপটি find()-এর।

★ REMEMBER

Directory তালিকা করার পুরোনো উপায় Files.newDirectoryStream(path, "*.{txt,java}"), যা একটি DirectoryStream<Path> দেয় এবং for-each loop দিয়ে iterate করা হয়। নতুন code-এ Files.find() ব্যবহার করুন, তবে exam-এ যেকোনোটি চিনতে পারা চাই।

সংক্ষিপ্ত রিভিউ

File ও path

  • Absolute path / বা drive letter দিয়ে শুরু হয়; বাকি সব relative। Path symbol: . = বর্তমান, .. = parent।
  • File constructor ব্যবহার করে; Path একটি interface, তৈরি হয় Path.of(), Paths.get(), FileSystems বা URI দিয়ে। রূপান্তর toPath() / toFile() দিয়ে।

Path নিয়ে কাজ

  • Path immutable — assign না করা method call কিছুই করে না। toString()-ই একমাত্র method যা String দেয়।
  • getNameCount(), getName() ও subpath() root বাদ দেয় এবং ভুল index-এ IllegalArgumentException ছোড়ে।
  • resolve() = concatenation (absolute argument জেতে)। relativize()-এ দুটি path একই ধরনের হতে হবে। normalize() textual; toRealPath() file system স্পর্শ করে এবং না থাকলে throw করে।
  • createDirectory() বনাম createDirectories(); delete() বনাম deleteIfExists(); copy()/move()-এ REPLACE_EXISTING লাগে আর এগুলো কখনো file-কে directory-র "ভেতরে" রাখে না।

I/O stream

  • Byte (InputStream/OutputStream) বনাম character (Reader/Writer); input বনাম output; low-level (কেবল file class) বনাম high-level (বাকি সব)।
  • Wrap করার সময় কখনো family মেশাবেন না। InputStream/Reader ইত্যাদি abstract। PrintReader বলে কিছু নেই।
  • read() int দেয়, stream-এর শেষে -1; buffered overload-এর return মান সবসময় ব্যবহার করুন।

Files-এর সুবিধাজনক method

  • readString(), readAllBytes(), readAllLines() সবকিছু memory-তে তোলে; lines() lazy এবং Stream দেয়।
  • NIO.2-এর stream method গুলো try-with-resources দিয়ে বন্ধ করতেই হবে।

Serialization

  • Serializable একটি marker interface; প্রতিটি instance member হয় serializable, transient, নয়তো null। Record-কে স্পষ্টভাবে implement করতে হয়।
  • Deserialization-এ serialized class-এর কোনো constructor বা instance initializer চলে না — কেবল প্রথম non-serializable parent-এর no-arg constructor চলে।
  • readObject() EOFException পর্যন্ত loop করা হয়; এটি ClassNotFoundException declare করে।

User ও advanced API

  • System.out/System.err হলো PrintStream (নীরব ব্যর্থতা); System.in একটি InputStream। এগুলো বন্ধ করবেন না।
  • Console হলো System.console()-এর singleton যা null হতে পারে; readPassword() char[] দেয়।
  • mark()/reset()/skip(); আগে markSupported() চেক করুন।
  • readAttributes() read-only, getFileAttributeView() updatable (setTimes())। walk() default-এ link অনুসরণ করে না; find() BiPredicate নেয় ও depth চায়।
