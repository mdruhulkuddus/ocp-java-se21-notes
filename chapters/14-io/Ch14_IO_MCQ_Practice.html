Q1Stream classes

Which class would be best to use to read a binary file into a Java object?

  • A. BufferedStream
  • B. FileReader
  • C. ObjectInputStream
  • D. ObjectOutputStream
Show Answer
C

Putting data into a structured object means deserializing, so ObjectInputStream is the right choice. BufferedStream is not a real I/O stream class. ObjectOutputStream exists but serializes rather than deserializes. FileReader could read text and build an object by hand, but the question specifies binary data.

Q2Paths

Assuming that / is the root directory within the file system, which of the following are true statements?

Choose all that apply.

  • A. /home/parrot is an absolute path.
  • B. new File("/home") will throw an exception if /home does not exist.
  • C. new File("/home").delete() will throw an exception if /home does not exist.
  • D. A Reader offers character encoding, making it more useful when working with String data than an InputStream.
Show Answer
A · D

Paths beginning with the root directory are absolute, so A is correct. B is wrong because you can freely create a File reference to something that doesn't exist. C is wrong too — delete() simply returns false when it can't delete. D is correct: character stream classes include convenience methods for String data.

Q3Console

What are possible results of executing the following code?

public static void main(String[] args) throws IOException {
   String line;
   var c = System.console();
   Writer w = c.writer();
   try (w) {
      if ((line = c.readLine("Enter your name: ")) != null)
         w.append(line);
      w.flush();
   }
}

Choose all that apply.

  • A. The code runs, but nothing is printed.
  • B. The code prints what was entered by the user.
  • C. The code behaves the same if throws IOException is removed.
  • D. A NullPointerException may be thrown.
Show Answer
B · D

When it works, the code prompts for input and echoes it, so B is right. But System.console() returns null if a console is unavailable, and there is no null check before c.writer() — so D is right as well. C is wrong because the Writer methods throw a checked IOException, which must be declared.

Q4Files methods

For which value of path sent to this method would it be guaranteed to output Success?

public void removeBadFile(Path path) {
   if(Files.isDirectory(path))
      System.out.println(Files.deleteIfExists(path)

  • A. path refers to an empty directory in the file system.
  • B. path refers to a directory with content in the file system.

Q5walk / find

Assume that the directory /animals exists and is empty. What is the result of executing the following code?

Path path = Path.of("/animals");
try (var z = Files.walk(path)) {
   boolean b = z
      .filter((p,a) -> a.isDirectory() && !path.equals(p))   // x
      .findFirst().isPresent();                              // y
   System.out.print(b ? "No Sub" : "Has Sub");
}
  • A. It prints No Sub.
  • B. It prints Has Sub.
  • C. The code will not compile because of line x.
  • D. The code will not compile because of line y.
Show Answer
C

Files.walk() returns a Stream<Path>, and filter() on a Stream takes a one-parameter Predicate, not the two-parameter form. The BiPredicate shape belongs to Files.find(). Rewritten with find() (and a maxDepth) the output would be Has Sub, since the directory is empty and the ternary is deliberately reversed.

Q6Serialization

What would be the value of name if the instance of Eagle created in main() were serialized and then deserialized?

class Bird {
   protected transient String name;
   public Bird() { this.name = "Matt"; }
}
public class Eagle extends Bird implements Serializable {
   { this.name = "Olivia"; }
   public Eagle() { this.name = "Bridget"; }
   public static void main(String[] args) {
      var e = new Eagle();
      e.name = "Adeline";
   }
}
  • A. Adeline
  • B. Bridget
  • C. Matt
  • D. null
Show Answer
C

The key is that while Eagle is serializable, its parent Bird is not — so none of Bird's members are serialized. During deserialization Java calls the constructor of the first non-serializable parent, which is Bird, setting name to Matt. None of Eagle's constructors or instance initializers run.

The snippet attempts to create the directory only if the link's target exists and is a directory — and createDirectory() throws if the target already exists, so "always" is wrong and B is right. Q8Files read

Assuming /fox/food-schedule.csv exists with the contents shown, what is the expected output of calling printData() on it?

// 6am,Breakfast / 9am,SecondBreakfast / 12pm,Lunch / 6pm,Dinner

void printData(Path path) throws IOException {
   Files.readAllLines(path)                      // r1
      .flatMap(p -> Stream.of(p.split(",")))     // r2

  • A. The code will not compile because of line r1.

Q9read / write

Given the following method and file1 containing ABCDEF, which statements are correct?

public void copyFile(File file1, File file2) throws Exception {
   var reader = new InputStreamReader(new FileInputStream(file1));
   try (var writer = new FileWriter(file2)) {
      char[] buffer = new char[5];
      while(reader.read(buffer) != -1) {
          writer.write(buffer);
          // n1
      }
   }
}

Choose all that apply.

  • A. The contents of the copied file are: ABCDEF
  • B. The contents of the copied file are: ABCDEFBCDE
  • C. If we check file2 on line n1 after five iterations, it may be empty.
  • D. This method contains a resource leak.
Show Answer
B · C · D

The method compiles, but the return value of read(buffer) is never used, so the final partial read leaves stale characters in the buffer — producing ABCDEFBCDE, and it would only copy correctly for files whose length is a multiple of 5. Without a flush(), data may not have reached disk yet, making C correct. And reader is never closed, which is the resource leak in D.

Q11Wrapping

Which classes will allow the following to compile?

var is = new BufferedInputStream(new FileInputStream("z.txt"));
InputStream wrapper = new ____________________ (is);
try (wrapper) {}

Choose all that apply.

  • A. BufferedInputStream
  • B. BufferedReader
  • C. FileInputStream
  • D. ObjectInputStream
Show Answer
A · D

The reference type is InputStream, so the class must inherit InputStream — that eliminates BufferedReader. It must also accept another stream as input, which rules out FileInputStream (it operates on a file). Both BufferedInputStream and ObjectInputStream are high-level input streams; there is no rule against wrapping a BufferedInputStream in another one. Note that try-with-resources can use a resource declared beforehand.

Q14Path API

What is the output of the following code?

23: p1.normalize().relativize(Path.of("/lion"));
24: System.out.println(p1);

26: var p2 = Path.of("/zoo/animals/bear/koala/food.txt");

Q17NIO.2

Which are true statements?

Choose all that apply.

  • A. NIO.2 includes a method to delete an entire directory tree.
  • B. NIO.2 includes a method to traverse a directory tree.
  • C. NIO.2 includes methods that are aware of symbolic links.
  • D. Files.readAttributes() is often more performant since it reads multiple attributes rather than accessing individual ones.

Q18mark / skip

Assume reader is a valid stream whose next characters are PEACOCKS. Which is true about the output?

var sb = new StringBuilder();
sb.append((char)reader.read());
reader.mark(10);
for(int i=0; i<2; i++) {
   sb.append((char)reader.read());
   reader.skip(2);
}
reader.reset();
reader.skip(0);
sb.append((char)reader.read());
System.out.println(sb.toString());
  • A. The code may print PEAE.
  • B. The code may print PEOE.
  • C. The code will always print PEOE.
  • D. The code will always print PEOA.
Show Answer
B

P is appended first, then the position is marked before E. E is appended and AC skipped; then O is appended and CK skipped. reset() returns to just before the E, skip(0) does nothing, and the final read() appends E — giving PEOE. C is wrong because mark() may not be supported, so only "may print" is safe.

Q19Path comparison

Assuming the directories and files exist and are not symbolic links, what is the result?

var p1 = Path.of("/lizard",".").resolve(Path.of("walking.txt"));
var p2 = new File("/lizard/././actions/../walking.txt").toPath();
System.out.print(Files.isSameFile(p1,p2));
System.out.print(" ");
System.out.print(p1.equals(p2));
System.out.print(" ");
System.out.print(Files.mismatch(p1,p2));
  • A. true true -1
  • B. true false -1
  • C. true false 0
  • D. false true -1
Show Answer
B

Simplifying the redundant path symbols, both p1 and p2 represent /lizard/walking.txt, so isSameFile() returns true. But equals() compares path values literally without reducing symbols, so it returns false. Finally mismatch() sees identical contents and returns -1.

Q20move()

Assume monkey.txt exists in the current working directory. Which statement about this snippet is correct?

Files.move(Path.of("monkey.txt"), Path.of("/animals"),
   StandardCopyOption.ATOMIC_MOVE);
  • A. If /animals/monkey.txt exists, it will be overwritten at runtime.
  • B. If /animals exists as an empty directory, /animals/monkey.txt will be the new location of the file.

Q31delete

Which statements about Files.delete() and Files.deleteIfExists() are true?

Quick Revision — the chapter's core traps

  • Creation: Path is an interface (Path.of(), Paths.get()) — never new Path(...) or Path.get(...). File has no three-arg constructor and no (String, File) form.
  • Checked exceptions: most Files methods declare IOException, so calling them without throws or a catch is a compile error. Files.exists() is the notable exception.
  • Immutability: a Path method call whose result isn't assigned changes nothing.
  • Indices: getNameCount(), getName(), and subpath() exclude the root, are zero-indexed, and throw IllegalArgumentException on bad ranges.
  • resolve / relativize / normalize: an absolute argument to resolve() wins; relativize() needs matching path types; normalize() is textual while toRealPath() hits the disk and can throw.
  • copy / move: never place a file "into" a directory — the target is the new file's full path. Without REPLACE_EXISTING an existing target throws. createDirectories() is silent when everything exists; createDirectory() throws.
  • delete: delete() throws on a missing path, deleteIfExists() returns false; both need directories to be empty; symbolic links delete the link.
  • Wrapping: never mix Reader/Writer with InputStream/OutputStream, and remember the base classes are abstract. No PrintReader exists.
  • Reading: honour the return value of read(buffer); -1 ends a stream. readAllLines() gives a List (no filter()/map()), lines() gives a Stream that must be closed.
  • Serialization: members must be serializable, transient, or null — a bare Object field breaks it. Records need an explicit implements Serializable. On deserialization only the first non-serializable parent's no-arg constructor runs.
  • Console & system streams: System.console() may be null; new Console() doesn't compile; closing System.out/System.err fails silently while a closed input stream throws.
  • Advanced: mark() may be unsupported (so "may print"); setTimes() is view-only; walk() takes a Predicate and ignores symbolic links by default; find() takes a BiPredicate and a mandatory depth, where 0 means the start path alone.
